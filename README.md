After years of silent paper jams, blinking lights and "PC LOAD LETTER", the printer finally speaks — and it turns out it has been paying very close attention. This entry gives the office printer a single, devastating line: it has printed your boarding pass, your divorce papers and your 2 a.m. resignation letter, so it knows more about your life than your therapist does, and unlike her, it never runs out of toner. The program prints that one line to stdout and writes the identical line to /output/entry.txt, using only the Python standard library, deterministically, every run.

## Run it

```sh
python3 main.py
```
